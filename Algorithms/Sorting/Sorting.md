# Selection Sort Algorithm

## What is Selection Sort?
Scans the array  finding the smallest elements and swapping them from the begging, gradually building the sorted array from the bottom up.

## What is the Time Complexity ?

**Worst Case  $O(n^2)$**
**Average Case - $O(n^2)$**


## Why is the Time Complexity $O(n^2)$

Because the sort requires a nested for loop, causing the number of operations to grow quadratically as the inputs get larger
